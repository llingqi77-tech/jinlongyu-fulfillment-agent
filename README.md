# 金龙鱼缺货履约 Agent 工作台

PC 端 Web 演示：在易分销背景上通过浮动入口打开 **92vw×90vh** 弹窗工作台，以**当日缺货 PO** 为数据底表，支持运营 / 销售 / 采购三角色并行履约。

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`（建议宽屏查看弹窗与表格）。

## 演示流程

1. 点击右下角 **AI** 浮动按钮 → 打开工作台，自动加载今日缺货 PO
2. **运营**：查看「今日缺货 PO」与运营总览 → 销售/采购完成后点击「生成 PO」确认写入
3. **销售**（切换角色）：「按客户/酒店」→ 选择酒店 → 登记「必须当期到货 / 不急」
4. **采购**（切换角色）：「按品处理」→ 展开酒店子表 → 录入供应商 / 金额 / ETA / 加急费
5. 酒店全部缺货行完成后显示 **100% 履约完成** Banner

## 导航

| 导航项 | 说明 |
|--------|------|
| 今日缺货 PO | 共同底表，三角色可穿透详情 |
| 按品处理 | 采购待寻源，含酒店子表 |
| 按客户/酒店 | 销售按酒店履约 |
| 我的任务 | 按角色过滤待办 |
| 协同与 Agent | 时间线 + Mock 对话 |

## 技术栈

- Vite + React 18 + TypeScript
- Tailwind CSS
- Zustand（`shortageStore`）
