# 金龙鱼缺货履约 Agent 工作台

PC 端 Web 演示：在易分销背景上通过浮动入口打开 **92vw×90vh** 弹窗工作台，以**当日缺货待转单**为数据底表，支持运营 / 销售 / 采购三角色并行履约。UI 采用 **橙色主题传统 SaaS**（暖色画布、白卡片、品牌橙 CTA/选中态、Inter + JetBrains Mono），见 [`design.md`](design.md)。

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`（建议宽屏查看 Pipeline 与任务中心）。

## 界面结构

- **顶部**：角色切换（运营 / 销售 / 采购）
- **履约 Pipeline**（四阶段，全员可见，统计按 **SKU 去重**）：
  1. 运营创建待履约任务并提供履约建议
  2. 销售确认产品履约方式（直发 / 正常补货 / 延期 / 当期到货 / 产品平替）
  3. 采购完成缺货产品采买（仅「当期到货」SKU）
  4. 完成履约任务（客户签收）
- **KPI 面板**：预计履约数量、实际履约数量、签收进度
- **任务中心**：按当前角色展示待办；点击 Pipeline「待完成」数字可筛选任务

## 演示流程

1. 点击右下角 **AI** → 加载今日缺货 mock 数据
2. **运营**：打开任务后 Agent 自动生成履约建议（可编辑/重新生成）→ 确认后流转销售
3. **销售**：查看运营建议，选择履约方式  
   - 直发 / 正常补货 / 产品平替 → 生成 **OrderDirect** 销售出库单  
   - 延期 → 生成 **Backorder** 销售出库单  
   - 当期到货 → 转采购
4. **采购**：查看系统推荐 3 家供应商，标记有货/无货，选用或手动录入供应商与金额 → **Agent 生成采购订单** → 一键确认写入金龙鱼采购系统
5. 形成出库单或采购确认后 **预计履约数量** 增加；**模拟签收**（按钮或定时）后 **实际履约数量** 与 Pipeline 第 4 阶段更新
