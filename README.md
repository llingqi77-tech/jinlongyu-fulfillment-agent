# 金龙鱼履约 Agent 工作台

移动端优先的 Web 演示应用，仿智谱 AutoGLM 白极简风格，演示待转单 → 销售订单 → 缺货 → 采购单全流程。

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`（手机可调开发者工具切换移动端视图）。

## 演示流程

1. **上传** 图片或 PDF → 自动解析 → 对话显示「待转单已解析完毕」，追踪页显示待转单已生成（流程暂停）
2. **修改** 文本或点麦克风（语音 Mock）→ 「待转单已更新」
3. 点击 **确认，并转为销售订单** → 库存匹配 → 缺货信息表（流程暂停）
4. 线下沟通后点击 **采购订单生成** → 填写供应商与金额 → 采购单写入完成

任意阶段发送指令会显示「agent执行中」+「系统操作中」浮条，并自动切到「追踪」页。

## 技术栈

- Vite + React 18 + TypeScript
- Tailwind CSS
- Zustand 状态机

## 构建

```bash
npm run build
npm run preview
```
